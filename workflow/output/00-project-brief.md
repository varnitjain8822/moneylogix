## Core Features

- Real-time stock price tracking with WebSocket updates
- AI-powered emotional trading advisor using Sarvam AI
- Paper trading with virtual portfolio management
- Strategy backtesting with historical data
- Multi-agent system with 16 specialized agents and review loops
- Technical analysis with 14 indicators (SMA, EMA, MACD, RSI, Bollinger, ATR, OBV, Stochastic, VWAP)
- News aggregation and sentiment analysis
- Portfolio health monitoring with Position Doctor
- Risk profiling and strategy recommendations
- User authentication and portfolio management
